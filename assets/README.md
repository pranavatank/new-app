# Hisab App Assets

## Required Assets

Place the following image files in this directory:

1. **icon.png** (1024x1024) - App icon
   - Use a rupee symbol (₹) on a gradient background (#5B5FEF to #8B5CF6)

2. **splash.png** (1284x2778) - Splash screen
   - Same rupee symbol centered on #5B5FEF background

3. **adaptive-icon.png** (1024x1024) - Android adaptive icon
   - Same as icon.png but with safe zone padding

4. **favicon.png** (48x48) - Web favicon
   - Smaller version of icon

## Quick Generation

You can use online tools like:
- https://www.appicon.co/
- https://icon.kitchen/

Or use Expo's asset generation:
```bash
npx expo-generate-icons
```
